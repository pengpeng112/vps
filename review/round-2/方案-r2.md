## 四、在线深层清理升级流程 v2（顺序：R1 试点 → R3 → R4 → R2，分歧#15）

通道：PC → DMIT(28722) → 排障口(132xx) → 设备 root。每台全程约 8 分钟。

**Phase 0 预检与内容级快照（每台）**
1. `grep DEVICE_ID /etc/routermgmt/agent.conf` = 预期，否则停；
2. 基线：health 200、心跳最近一拍年龄<70s、隧道实例数、`iptables -L FORWARD -v -n` 首行计数（用户流量代理指标，分歧#20）；
3. **内容级快照**（分歧#18）：设备上 `tar czf /tmp/pcdn-snap.tar.gz`（含 /etc/rc.local、/etc/crontabs/root、/etc/init.d/{九件套}、/www/cgi-bin/{四端点}、/usr/bin/install_*.sh、字面花括号两文件、mbox_init*）→ 二段 scp 落 DMIT → PC 留存 `backups/pcdn-clean-{设备}-20261014/`，**拉回后 tar -t 验证可读**；
4. **存在性清点**（分歧#4）：对 flash-snr 全名单逐项 `ls`/`grep -l` 记录（字面花括号文件、mbox_init.sh、mboxinit.sh、netbox_daemon.service、zcon-*、start_jcgqos、数据盘 by-agent/by-daemon/by-watcher/initmindevice.sh/data1/docker），生成该台实际残留清单——删除范围=清单，不预设。

**Phase 1 自启层先行（分歧#5：停服务在杀进程之前，对齐刷机序）**
- 对清点到 的 init.d 残留（九件套口径：mbox/start_client_manage/timeRestart/hole/start_get_versionInfo/netbox_daemon.service/zcon-edge-service/zcon-ng/start_jcgqos）：`[ -f /etc/init.d/X ] && { /etc/init.d/X stop 2>/dev/null; /etc/init.d/X disable 2>/dev/null; }`——**stop 前先 `head -30` 读脚本确认其 stop 逻辑不触网络**（分歧：codex#3；逐台留档）；
- rc.local 新版（本机快照为底本，语义锚点替换而非行号，分歧#24 补充：注释 `install_mbox.sh &`/`install_pdnterminal.sh &` 两行为 `# disabled-pcdn …`；R2 另将 112-113 行块移至唯一 `exit 0` 之前）：tmp+`sh -n`+md5+`mv` 原子替换；**全部四台**（非仅 R2）校验 `exit 0` 唯一且为末行（分歧：grok#10）；
- crontab 新版 = 本机当前内容（Phase 0 重读，防 agent 并发写入丢失，比对 md5 后再生成）− `factory checkMem` 行 + `0 0 * * * /sbin/reboot #routermgmt-reboot`（R2 专项，**见人工终审项**）+ `*/5 * * * * /etc/routermgmt/connlog.sh #routermgmt-connlog`（R2 缺失项，前置确认 /etc/routermgmt/connlog.sh 存在）；同样 tmp+mv 原子替换 → `/etc/init.d/cron restart` → `crontab -l` 读回与预期 diff。

**Phase 2 进程层（PID 级，分歧#1）**
- `ps w | grep install_` 取**确切 PID 清单**（人工/脚本核对 cmdline 为 `/bin/bash /usr/bin/install_pdnterminal.sh` 等），逐 PID `kill`；**禁止裸 pkill -f**；
- 复验 `ps w | grep "[i]nstall_"` 为空；若被 respawn 拉起 → 回 Phase 1 补 disable。

**Phase 3 文件层（删除范围=Phase 0 清点清单）**
