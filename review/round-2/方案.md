## 三、目标与边界

**目标**：把 R1/R2/R3/R4 在线升级到 R7/R8/R9 的"深层清洁终态"，并把这套口径固化进后续刷机流程。

**硬边界（用户红线）**：
1. **在线升级不得影响远程控制**：全程不动 mgmt-tunnel、不重启隧道/agent/mihomo、不断排障口、不改任何网络配置；
2. **在线升级不得影响使用**：不主动重启设备（R2 的每日重启 cron 修复后由次日 00:00 自然生效）、不动 WiFi/WAN/LAN 转发路径、QUIC 规则仅追加自愈不改语义；
3. 只处理 SN-R 系列（iptables 设备）；雅典娜（nftables）不在本流程范围；
4. 所有远端文件修改一律整文件 base64 推送 + md5 对拍（SOP 增补（四）sed 三次翻车教训），绝不经 SSH 链 sed。

## 四、在线深层清理升级流程 v1（每台约 5 分钟，R2→R4→R3→R1 顺序）

执行通道：PC → DMIT(28722) → 排障口(132xx) → 设备 root。逐台执行、逐台复验，单台失败不影响其余。

**Phase 0 预检与快照（每台）**
1. 身份核对：`grep DEVICE_ID /etc/routermgmt/agent.conf` 必须等于预期（防串口）。
2. 基线确认：健康 200、心跳 30 秒内两连拍、隧道实例数记录。
3. 快照取证：拉取并本地留存 `/etc/rc.local`、`/etc/crontabs/root`、`ls /etc/init.d`、`ls /www/cgi-bin`、`/usr/bin/install_*.sh` 的 md5 与原文（回退依据，存 `backups/pcdn-clean-{设备}-{日期}/`）。

**Phase 1 进程层（杀休眠安装器）**
- `pkill -f install_pdnterminal.sh; pkill -f install_mbox.sh`（当前为纯休眠 bash，杀掉零影响）
- 复验 `ps w | grep "[i]nstall_"` 为空。

**Phase 2 文件层（删执行者）**
- `rm -f /usr/bin/install_pdnterminal.sh /usr/bin/install_mbox.sh`；
- 按存在性删除已知 PCDN 二进制：`/usr/bin/rathole /usr/bin/zcon-ng /usr/bin/zcon-edge-arm64`（先 ls 确认再删；本轮 R1-R4 实测均不存在，仅 R7 案有过）。

**Phase 3 自启层（init.d + crontab + rc.local）**
- init.d：对 `mbox / start_client_manage / timeRestart / hole / start_get_versionInfo` 逐个 `[ -f ] && { stop; disable; rm }`；
- crontab：整文件重写 `/etc/crontabs/root`（保留其余行，仅去 `factory checkMem` 行）→ `/etc/init.d/cron restart`（cron 重启不涉网络，排障口与隧道均不受影响）→ `crontab -l` 读回验证；
- R2 专项：同一份重写中加入 `0 0 * * * /sbin/reboot #routermgmt-reboot`（与 R1/R3/R4 对齐，恢复每日定时重启）；
- rc.local：整文件 base64 推送新版——第 96/98 行注释为 `# disabled-pcdn ...`（R1 已是此态）；R2 将 112-113 行块移至唯一 `exit 0` 之前（修复死代码）；推送后 `sh -n /etc/rc.local` 语法校验 + 逐行 grep 验证放置。rc.local 只影响下次开机，本次零影响。

**Phase 4 云端点层**
- `rm -f /www/cgi-bin/cgi-exec cgi-upload cgi-download cgi-backup`（保留 luci；这些端点不属正常管理面）。

**Phase 5 数据盘层（在线安全版，与 R7 终态同口径不同手段）**
- 预检：`mount | grep mmcblk0p6` 记录嵌套挂载；`ps w | grep "[d]ockerd"` 确认厂商 docker 是否在跑；
- 若有嵌套 `/mnt/mmcblk0p6/docker` 子挂载：先 `umount`（busy 则记录跳过、不强拆）；
- `rm -rf /mnt/mmcblk0p6/{docker,lost+found}`——**保持挂载不动、不 umount 主分区、不 dd**（R7 的 dd 抹签名留给刷机流程；在线只清内容）。分区留在挂载态但内容为空=验收口径达成；下次开机驱动会重格为空 ext4（R7 终审已证此为固件固有行为，无害）。

**Phase 6 每台终验（12 项，全绿才下一台）**
残留六项：`ps` 无 install_/PCDN 进程；`ls /usr/bin/install_*` 空；init.d 残留 0；crontab 无 checkMem；rc.local 无激活钩子（注释行允许）；`ls /mnt/mmcblk0p6` 空；cgi-bin 仅 luci。
不影响六项：健康仍 200；心跳 30 秒内两连拍（证明 agent/隧道未受影响）；隧道实例数与基线一致；`curl -x http://127.0.0.1:7890 https://api.ipify.org` 出口 IP 正常（证明代理转发未受影响）；QUIC REJECT 仍首位；netprobe 日志仍在追加。
R2 加验：`sh -n` 通过、exit 0 唯一且在末尾、`crontab -l` 含 #routermgmt-reboot。

**Phase 7 回退预案**
- rc.local/crontab：Phase 0 快照 b64 推回即回退（不需重启即恢复 cron 生效语义）；
- init.d/CGI/脚本：快照原文件推回；
- 数据盘：空分区即终态，无需回退；
- 全程未动 mgmt-tunnel/authorized_keys/网络配置，远程控制通道无回退需求。

**离线设备**：R5/R6 回线后同流程补做，并加做 QUIC REJECT-SELFHEAL（init.d/mihomo 追加两条+当场 iptables 自愈两条，R2-R6 竞态同源修复清单的最后两台）；R7/R8 已清洁仅需例行巡检。
