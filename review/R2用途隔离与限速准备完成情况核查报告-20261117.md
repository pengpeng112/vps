**语义说明（核查者请重点确认这一条）**：PROXY 是 select 手选组，成员含 BULK 是**有意保留手选能力**（故障时人工可切）；AUTO/NODE-PICK 是 fallback 自动组，**隔离的判定标准=自动组无 BULK**，而非 PROXY 无 BULK。
