## 5. 历史踩坑与操作禁令（执行前必查，净版 1–14）

1. **禁手改设备正式 mihomo 配置**：曾致 R4 崩溃循环 2h17m；所有变更走广州平台发布。
2. **X14 密钥铁律**：`MASTER_KEY`/JWT 对拍只认运行中进程/容器 `environ`，禁信 `.env` 旧值（曾致 TOTP 全 401）。
3. **`golden.yaml` 与迁移脚本强制 LF**：CRLF 会随 `go:embed` 进入设备致 mihomo 拒解析。
4. **Docker 重建 API 后必须重启 web**：nginx 启动时一次性解析上游容器 IP（适用 DMIT 温备）。
5. **控制面迁移须垫高 `configs.max(version)`**：须高于设备 `highest_accepted`，防 agent 版本门拒收。
6. **CF 节点严禁设 primary**：`switch_node` 的 `expect_exit_ip` 期望出口 IP，与 CF 边缘 IP 不一致必回滚。
7. **`self-heal` 锁定 v3.1 禁退 v4**：v4 的 `pidof` 误判会在配置应用中途重启 agent（R6 事故）。
8. **严禁多会话并发操作同一资源**：开工必须跑 `python scripts/session_guard.py status`，按标准 scope 拿锁后写、收尾解锁。
9. **发布验证看三处且必含冷启动等效验证**：核对 `tasks.status=ok` + 设备文件 mtime/内容 + 9090 组状态；且需验 mihomo 重启后配置与选择持久性（防复用同 SHA 假通过与 00:00 炸配置）。
10. **恢复 `select` 组（如 `PROXY=AUTO`）必须写穿 `cache.db`**：通过 `PUT /proxies/PROXY {"name":"AUTO"}` 并用 `bbolt get <cache副本> selected PROXY` 核验持久化；`set_proxy_state` 仅改内存态，00:00 重启会回滚。
11. **嵌套 SSH 命令禁本地 `$()` 展开**：经广州跳转执行设备检查一律用双层 Paramiko `direct-tcpip` + `stdin sh -s`，防止命令替换在广州侧提前求值造假数据。
12. **告警管道双端配置**：GZ unit 的 `ALERT_WEBHOOK_URL` 与 GIA 本地 `/etc/alerts/webhook.url` 缺一不推。
13. **临时实例防误杀**：严禁按进程名或端口盲杀（如 `pkill sshd`/`mihomo`）；临时沙箱进程须记 PID、启动时间与完整 argv 精准清理（11-18 误诱发核心短重启教训）。
14. **计量域名解析禁走本机 dnsmasq**：在透明代理开启的路由器上解析机场/节点域名必须直连公共 DNS 并双层拒收 `198.18.x` fake-ip 及非公网 IP，否则规则全废。
