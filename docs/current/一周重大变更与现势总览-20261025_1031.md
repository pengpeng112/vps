## 5. 教训与禁令（本周血泪，执行前必读）

1. **禁止手工 sed/编辑设备上的 mihomo config.yaml**——R4 崩溃 2h17m 的根因。一切变更走平台发布（GZ 8080 API）
2. **X14：MASTER_KEY/JWT 对拍只认运行中进程 environ**——`.env`/unit 文件可能是过时值
3. **golden.yaml 必须 LF**——CRLF 会随 go:embed 进设备配置（mihomo 拒解析）
4. **DMIT/广州 docker 重建 api 后必须 restart web**——nginx 启动时一次性解析上游容器 IP
5. **控制面迁移必须垫高 configs.max(version) 高于设备 highest_accepted**——否则 agent 版本门拒收、任务 expired
6. **CF 节点不得设 primary**——switch_node 的 expect_exit_ip 校验会失败（出口是源站 IP 非 CF 边缘）
7. **self-heal v3.1 不得回退 v4**——v4 的 pidof 误判会在配置应用中途重启 agent（R6 回滚事故）
8. **多会话并行禁止同时操作同一后端**——10-31 会话A/B 各自替换过 GZ 二进制，靠功能合集侥幸无冲突；开工前先读本文§1 确认现势
9. **发布验证看三处**：tasks.status=ok + 设备文件 mtime/内容 + 9090 组状态；只看版本号相等会被"复用同 sha 版本"骗过
10. **告警管道两处 URL**（GZ unit + GIA 本地文件）都要配，缺一不推
11. **恢复 PROXY=AUTO 必须用 `PUT /proxies/PROXY {"name":"AUTO"}`**（写穿 cache.db）——`set_proxy_state` 任务只改运行态，00:00 重启即被 cache 旧钉选回滚（R7 实证 + bbolt 铁证，11-01）
12. **发布验收必须含冷启动等效验证**（mihomo 完整重启一次或等 00:00）——R7 v6 当晚全过、次日凌晨才暴露（11-01）
11. **select 组选择修复必须 bbolt 验 cache 写穿**——R7 实证：set_proxy_state 任务 ok 不等于持久化，00:00 reboot 后 cache.db 旧钉选回滚（11-01）；验证手段 `bbolt get <cache副本> selected PROXY`
12. **嵌套 SSH 命令里 `$()` 在本地展开**——检查脚本经广州转发时所有 `$(...)` 在 GZ 侧求值得出假数据（11-01 R7 晨检教训）；设备检查一律双层 Paramiko direct-tcpip + stdin `sh -s`
