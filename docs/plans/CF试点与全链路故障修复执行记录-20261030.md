## 二、修复的故障（按发现顺序）

### 1. R4（坊子）mihomo 崩溃循环 —— 外网中断 12:49–15:06（约 2h17m）

- 现象：`/etc/mihomo/config.yaml` 12:49 被写坏 → mihomo 每 5 秒 fatal "yaml: line 4: did not find expected key"，代理全断。
- 根因：**12:49 的一次设备端手工写入把 DMIT-HY2 节点写成顶格 `- name:`**（其余节点均 2 空格缩进）。tasks 表证实该时刻无任何平台任务；v21 平台 bundle 于 10:07 经 switch_node 正常下发并通过 mihomo_validate 校验——即**坏块不是平台渲染器产物**（渲染器 hysteria2 分支带缩进带引号，代码核对无误）。此写入与 10-29 遗留的"DMIT HY2 手工 sed 注入"操作吻合（正是待办里"不要手工 sed"所警告的）。
- 修复：sed 补 2 空格缩进（`config.yaml.broken-crlf-1030` 备份留存）→ mihomo -t 通过 → 重启 → 9090/流量恢复，NODE-PICK 延迟 165ms。
- 防复发：已确认 desired=accepted=21，平台不会重推；R4 现文件含修正版 DMIT-HY2。**下次平台发布会自然移除 DMIT-HY2（不在节点表），属预期行为。**

### 2. GIA→DMIT 管理中继断链 —— s-relay 指向 DMIT 旧 IP

- 现象：全舰队 agent 心跳 http=000。
- 链路：设备 →(SSH -L 18443)→ GZ:8443 →(gz-relay)→ GIA:8443 →(s-relay)→ DMIT:8443。断点在 s-relay：仍指向旧 IP `179.255.137.64`，重试失败计数 80。
- 修复：sed 改为 `69.63.219.156`，restart，GIA 本机 8443 恢复监听。

### 3. DMIT 重启后 web 容器起不来 —— wg0(10.10.0.1) 丢失

- 现象：DMIT 12:19 重启后 routermgmt-web-1 崩溃循环（`nginx: host not found in upstream "api"` + 端口绑定依赖的 wg0 无 IP），宿主 8443 无人监听 → 即使中继修好 API 仍不可达。
- 修复：① 重建 wg0（仅地址 10.10.0.1/24，无 peer）+ 新增 `wg-placeholder.service` 持久化；② `/opt/mgmt/deploy` 下正规 `docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d` → web 正常绑定 `127.0.0.1:8443` 与 `10.10.0.1:8443`。
- ⚠️ 遗留：wg0 原有 peer 配置无处可寻（旧机手工配置未持久化）。若雅典娜经 WG 接入 DMIT 管理面，其通道仍断，需用 pkg-athena.json/备份重建 peer 后恢复。
