## 5. 实施步骤

### P1 在东京安装 sing-box

目标：这台空机器只增加一个 Hysteria2 入站。没有现成的 `/etc/sing-box/config.json`，不要把 `docs/reports/统一优化-20260927/hy2-20260930/tx_patch.py3` 原样拿来跑。那个脚本是给已经有 VLESS 的腾讯机器打补丁的。

1. 安装 SagerNet/sing-box **1.14.2** 的 linux-amd64 包，和腾讯节点同版本。装完执行 `sing-box version`，确认是 1.14.2。这个版本的资产找不到时停下来写明原因，不要改用 1.12 或更旧，也不要在没读配置差异的情况下换到 1.15 及以上。
2. 用 `secrets` 生成 40 位字母数字密码。写入 `F:\vps\backups\搬瓦工东京-HY2凭据-20260930.md`，字段至少包括：节点名 `BWG-HY2-JPTY-01`、host `74.82.203.175`、端口 `443/udp`、密码、证书路径。不要复用 `backups/TX-HY2节点凭据-20260930.md` 里的密码。
3. 证书放到 `/etc/sing-box/hy2/hy2.key` 与 `hy2.crt`，生成方式与腾讯补丁相同：`openssl req -x509 -newkey ec -pkeyopt ec_paramgen_curve:prime256v1 -nodes`，有效期 825 天，`CN=bing.com`。私钥 `0600`。
4. 配置写 `/etc/sing-box/config.json`，systemd 使用 `sing-box -C /etc/sing-box`，不要写到 `/usr/local/etc`。入站：

```json
{
  "type": "hysteria2",
  "tag": "hy2-in-443",
  "listen": "::",
  "listen_port": 443,
  "users": [{ "password": "<新密码>" }],
  "tls": {
    "enabled": true,
    "certificate_path": "/etc/sing-box/hy2/hy2.crt",
    "key_path": "/etc/sing-box/hy2/hy2.key"
  }
}
```

出站至少要有 `direct`。路由拒绝发往私网、链路本地、`127.0.0.0/8` 和本机公网 `74.82.203.175/32` 的代理流量，避免这台机器变成可打进 SSH 的跳板。不要加 obfs。不要加会把客户端限在很低速率的 `up_mbps`。日志级别 `warn`。

5. `sing-box check -C /etc/sing-box` 通过后再 `systemctl enable --now sing-box`。`ss -ulpn` 能看到 `:443`。`systemctl is-active sing-box` 为 `active`。
6. 若系统里已有防火墙，显式放行 `443/udp`，并保持 `22/tcp` 可达。现在没有 ufw，就不要为了这一步启用 ufw。
7. 打开 BBR：`sysctl net.ipv4.tcp_congestion_control=bbr`，并写入 sysctl 配置。失败只记录，不因此停工。
8. 从 R3 向 `74.82.203.175` 的 UDP 443 发几个包，同时在东京用 tcpdump 抓 `udp port 443`。包到了才进入 P2。抓包窗口结束就停 tcpdump。这一步是为了避开腾讯轻量「主机在听、平台丢掉 UDP」那种失败。
