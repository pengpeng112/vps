## 过程坑与处置

1. **GL 备份通道两次失败**：sshpass scp（gz 端空输出）→ paramiko SFTP（dropbear 无 sftp-server，EOF）→ 最终 **cat 原始字节流 + 双端 sha256 校验**（拉取方向、4KB 小文件、校验失败即停——与禁令 X1"推送"不同向且更严）。GL busybox 无 base64 命令亦被此法绕开。
2. 驱动串行纪律生效：GL 备份失败时批次自动停在 GL（不再向后），雅典娜/GL 改通道后单独完成。
