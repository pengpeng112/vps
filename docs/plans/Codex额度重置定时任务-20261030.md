# Codex 已获赠重置券一次性使用任务

用户授权：在 2026-10-30 北京时间 02:02 到期前十分钟，使用这一次即将到期的免费重置。

- Windows 任务：`Codex-UseExpiringReset-20261030-0152`，一次性，目标兑换时间 01:52:00（UTC+8）。Windows 触发器提前设为 01:50，程序等到 01:52 才允许兑换，以留出系统启动/调度余量。
- API 读取确认该券实际到期为 02:02:21；另一次 11-07 到期的券不在授权执行范围，脚本不会替代选择它。
- 脚本：`scripts/codex-reset-once.py`；凭现有本机 Codex 登录，通过官方 `account/rateLimits/read` 和 `account/rateLimitResetCredit/consume` 协议工作，不创建模型会话，不进行付费购买。
- 配置与稳定幂等键：gitignore 的 `backups/codex-reset-20261030.json`；任务 XML 快照也在 backups。日志：`logs/codex-reset/20261030.jsonl`，同样 gitignore。不复制账号 token 或口令到任务参数。
- 运行窗口为 01:52—02:00。提前运行、过晚补运行都不会消费；最多三次通信尝试，始终复用同一券 ID 和幂等键，避免丢失响应时重复消费。
- 当前券不存在且此前没有发起过兑换时，退出而不改用其他券；服务器返回 nothingToReset/noCredit 时记录结果，不声称重置成功。
- 最终以日志中的 redemption outcome=reset/alreadyRedeemed 及随后重新读取的限额为准。注册成功不代表未来兑换已经成功。

验证：实际 `--check` 只读读取成功；四项无网络模拟测试覆盖只读不消费、提前/过期不执行、重复启动只消费一次、响应丢失的同一幂等重试。没有执行真实 consume 来测试。

执行条件：同一 Windows 用户保持登录，电脑开机联网，Codex 本机登录仍有效。已设 WakeToRun/StartWhenAvailable，但唤醒仍受系统电源策略影响；若错过 02:00，脚本不会迟到消费。无需保持本对话窗口打开。

检查任务：`Get-ScheduledTaskInfo -TaskName Codex-UseExpiringReset-20261030-0152`。

取消任务：`Unregister-ScheduledTask -TaskName Codex-UseExpiringReset-20261030-0152 -Confirm:$false`。

官方协议依据：[Codex App Server：Earned rate-limit resets](https://learn.chatgpt.com/docs/app-server)。
