# AI 协作交接规范

修订：2026-11-21。本规范配套根目录 [AGENTS.md](../../AGENTS.md) 与 [跨 AI 协作入口](../AI协作入口.md)；交接记录仅用于事实同步，**不构成生产变更授权**。

## 1. 接手检查

1. 运行 `python scripts/session_guard.py status` 与 `git status --short`，识别他人锁和未提交改动。
2. 按 `AGENTS.md` §1 任务等级（T0/T1/T2）阅读 [现势总览](../current/现势总览.md) 与 [当前状态](../current/当前状态.md) 顶部 3 条。
3. 同一资源同一时间只由一个会话持锁修改；若发现他人锁，不得抢占或代解，仅在无冲突范围工作或协调后再推进。

## 2. MECE 记录分工（消除重复写三遍）

| 信息类型 | 唯一放置位置 | 触发条件 |
|---|---|---|
| 架构终态 / 设备表 / 未决项 / 踩坑禁令变化 | `docs/current/现势总览.md`（**原位更新表格，禁顶部叠补记**） | 仅终态或台账实质变化时 |
| 已验证的现网变更或重大代码/治理交付摘要 | `docs/current/当前状态.md` 顶部追加 ≤5 行 | 有现网变更或重大本地交付时（纯读免） |
| 详细步骤、检查点、命令证据与未完成交接 | `docs/plans/<主题>-YYYYMMDD-<身份>.md` | 现网写操作、≥3 步长任务或跨会话交接时（同主题优先追加） |
| 只读诊断报告与历史时点证据 | `docs/reports/` 或 `review/evidence-YYYYMMDD/` | 保留原始采集时点，不覆写旧结论 |
| 稳定操作 SOP | `docs/operations/`（每类仅留最新版） | 仅引用 `现势总览.md`，不复制易变拓扑 |
| 历史归档与路径映射 | `docs/archive/`、`scripts/archive/` + `docs/archive/YYYYMMDD-manifest.md` | 移动/归档时必附旧新路径与 SHA-256 |

## 3. 交接卡片标准格式

```text
任务：<主题>｜会话：<模型/工具-YYYYMMDD>｜时间：<本地时间>
授权与锁：<本轮用户授权范围>｜<已释放锁ID或无写锁>
完成：<具体文件/操作与改动摘要>
实测证据：<命令/输出摘要/SHA/验证时点；未验写“未验证”>
未验证或阻塞：<具体缺口与限制>
下一步：<最小精确动作（具体到文件、命令或待用户决策点）>
```

严禁将密码、完整 DSN、token、密钥、订阅 URL、WS 路径或业务原文写入任何交接记录。
