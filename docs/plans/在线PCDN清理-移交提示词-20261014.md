### 0. 总原则

1. **在线操作不能影响远程控制和使用。** 全程不重启设备，不重启、不重载 mgmt-tunnel、routermgmt、mihomo，不改网络、WiFi、iptables、防火墙，不断排障口。唯一允许的服务动作是 `/etc/init.d/cron restart`。
2. 顺序固定：**R1 试点全绿，并且只读回退演练通过之后**，才做 R3，然后 R4，最后 R2。一台失败只隔离该台，其余继续。
3. 每个破坏性动作前有快照，后有读回。禁止删了再说。
4. 结论分成：本次实测、历史报告、推断。验收输出原文留在证据文件里。
5. **本轮不要发挥。** 不要跑 `flash-snr.py`、`flash-batch.py`，不要重刷，不要改管理台、DO、git。方案第五节的脚本修复已经落地，不要再改刷机脚本。状态档写着离线的 R5/R7/R8/R9/R10/R11 即使此刻在线，也不在本轮。雅典娜不在本轮。
6. 检查命令自身失败（非零且没有可用 stdout）记「未知」，按失败处理，不得记干净。`grep -c` 命中 0 行时退出码是 1、stdout 是 `0`，这算有输出，不是未知。不要在设备侧开 `set -e`。
7. `wc -l` 的前导空格先 `tr -d ' '` 再比较。`ps w` 会截断命令行，核对进程用 `tr '\0' ' ' < /proc/<pid>/cmdline`。

### 2. 通道与口令

- 跳板：上面的 DMIT 命令。本机是 Windows，优先 PowerShell 7。有 Git Bash 可以用，但口令规则相同。
- 口令只从 `backups/SN-R系列凭证总览.md` 读取。R4 的网页口令、WiFi 口令都不是 SSH 口令；SSH 以 2026-10-03 更新（六）及之后仍有效的 Fleet SSH 条目为准。
- 口令进环境变量或 root 只读的临时文件（权限 600），用 `sshpass -e` 或 `sshpass -f`。**禁止 `sshpass -p`。** 禁止把口令写进命令行、证据文件、执行记录、当前状态、台账。会话结束删掉临时口令文件。
- 本机没有 sshpass 时，用 Python（paramiko）经 DMIT `direct-tcpip` 到 `127.0.0.1:排障口`。口令放在内存里，不写进仓库里的脚本。
- 引号：外层双引号包 DMIT 命令，设备命令用单引号。设备命令内部再用引号时只用双引号。内层单引号会在 DMIT 提前闭合。
- 设备 shell 是 BusyBox ash。不支持花括号展开。多路径删除逐个绝对路径写全。文件名本身带花括号的两个路径必须加双引号：`"/usr/bin/{install_mbox.sh}"` 和 `"/usr/bin/{install_pdnterminal.sh}"`。

推送与拉回：

- 改文件一律在本地改完，base64 从 stdin 送进设备：`base64 -d > /tmp/某.new`。不要把文件正文嵌进 ssh 参数。不要用 sed 经这条 SSH 链改远端文件。
- `sshpass -e` 不会吃掉 stdin。不要加关闭 stdin 的 `-n`。
- 推送后设备上 `md5sum` 必须与本地一致，然后才允许 `mv`。不一致就删掉 `.new`，正式文件不动。
- 拉快照同样要两端 md5 一致。推荐 base64 经这条 SSH 会话拉回。scp 可以，但 md5 不一致的包作废，不能当回退底本。
- `rc.local` 替换后 `chmod 755`。`/etc/crontabs/root` 替换后 `chmod 600`。crontab 不是 shell 脚本，不要对它 `sh -n`。

### 3. 禁令

- 禁止 `pkill -f`、禁止 `killall`。只对 `/proc/<pid>/cmdline` 已核对的安装器 PID 执行 `kill <pid>`。cmdline 里含 `grep`、`ssh`、`ash -c` 的不杀。
- 禁止 umount 数据盘主分区，禁止 dd，禁止执行 `/usr/sbin/update_docker.sh`。在线场景没有「下次开机帮你重格」这回事。
- 禁止动：`/etc/routermgmt/` 里的文件内容（只允许读和确认 `connlog.sh` 存在）、`/etc/init.d/` 里除清点九件套以外的脚本、`authorized_keys`、网络配置、WiFi、iptables、DO 旧库、git 提交。
- 九件套 init 脚本里，`head` 读到 `reboot`、`halt`、`poweroff`、`ifdown`、`wifi`、`iptables`、`firewall`、`/etc/init.d/network` 时，**禁止执行该脚本的 stop 或 disable**。只允许删它的 `S*` 软链（先 `readlink` 确认指向这个名字）和稍后 `rm` 脚本文件。`timeRestart` 默认按这条处理，除非全文读完能证明 stop/disable 不会重启。
- QUIC 验收失败只登记。禁止为了修好它去插 iptables。
- 发现清点名单以外的可疑文件：只写入遗留清单。本轮不删。

### 4. v3 补上的三处缺口（不做的话，这轮要么验收失败，要么次日伤到数据盘）

这三处是 10-14 下午 R11 实锤和方案自身 C3 口径对出来的，方案-r2 正文没写进操作步骤。

1. **init.d 文件本体要删。** Phase 1 的 stop/disable 只停服务。C3 要求九件套文件不在。Phase 3 必须把清点到的 `/etc/init.d/<名>` 逐个 `rm -f`。disable 之后仍留下的、且 `readlink` 指向这九个名字的 `S*` 软链也删。其他 `S*` 不动。
2. **rc.local 里行首未注释的 `/usr/sbin/update_docker.sh` 要注释成 `# disabled-pcdn: ` 加原行。** 已注释的不动。R11 上这条在数据盘没挂上时会 `mkfs.ext4` 整分区。R2 本轮会补上 00:00 重启，次日就会走到开机脚本。不删 `/usr/sbin/update_docker.sh` 这个文件，不运行它。
3. **安装钩子是注释，不是删行。** 未注释且行首为 `/usr/bin/install_mbox.sh` 或 `/usr/bin/install_pdnterminal.sh` 的，整行改为 `# disabled-pcdn: ` 加原内容。已是注释的不动。不要照搬 `flash-snr.py` 里的 `sed -i`。

`exit 0` 只允许出现一次，且是最后一行。不是一次就停该台，不要猜该留哪一行。只有 R2 需要把唯一的 `exit 0` 挪到文件末尾，其他行顺序不动。R1/R3/R4 如果已经满足，就不要为了「整理」再改位置。

### 5. 每台流程

记录该台设备侧 `date` 作为操作开始时间。

**Phase 0 预检与快照**

1. `grep DEVICE_ID /etc/routermgmt/agent.conf` 必须等于表内值。不等就停该台。
2. 基线原文留存：
   - `curl -sk -m 6 -o /dev/null -w '%{http_code}' https://127.0.0.1:18443/api/v1/health` 应为 200。不是 200 就停该台，不要开始删除。
   - `logread | grep heartbeat | tail -2`
   - `ps w | grep "[i]d_dropbear_mgmt" | wc -l`（只记基线。历史值 R1/R4=4，R2/R3=5，不一致不当成失败）
   - `iptables -L FORWARD -v -n | head -3`
   - `iptables -S FORWARD | grep 443 | head -1`（读一下，后面只比较，不修改）
3. 存在性清点。每一项用 `ls -l` 或 `test -e`，退出码写进清单。路径：
   - `/usr/bin/install_pdnterminal.sh`、`/usr/bin/install_mbox.sh`、`"/usr/bin/{install_mbox.sh}"`、`"/usr/bin/{install_pdnterminal.sh}"`、`/usr/bin/mbox_init.sh`、`/usr/bin/mboxinit.sh`、`/usr/bin/rathole`、`/usr/bin/zcon-ng`、`/usr/bin/zcon-edge-arm64`
   - `/etc/init.d/` 下：mbox、start_client_manage、timeRestart、hole、start_get_versionInfo、netbox_daemon.service、zcon-edge-service、zcon-ng、start_jcgqos

   - `/mnt/mmcblk0p6/` 下：docker、by-agent、by-daemon、by-watcher、initmindevice.sh、data1
   - `mount | grep mmcblk0p6`、`ps w | grep "[d]ockerd"`
   - 另记一行是否存在未注释的 `/usr/sbin/update_docker.sh`（`grep -n . /etc/rc.local` 里人工看，不要用 sed 改）
4. 快照只打包**实际存在**的这些小文件：`/etc/rc.local`、`/etc/crontabs/root`、清点到的 init.d、四个 cgi、清点到的 `/usr/bin` 安装器与二进制、存在的话再加上 `/usr/sbin/update_docker.sh`。先写清单文件，再 `tar czf /tmp/pcdn-snap.tar.gz -T /tmp/pcdn-snap.list`。不要打包 `/mnt/mmcblk0p6`。`rc.local` 或 crontab 没进包就停该台。
5. 拉回 `backups/pcdn-clean-<设备名>-20261014/`。PC 上 `tar -t` 能列出，且 md5 与设备一致。设备上的 `/tmp` 副本留着（重启会自己消失）。

**Phase 1 自启层（先切断开机入口，再谈进程）**

1. 对清点到的每个 init.d：先 `head -80` 留档。命中第 3 节的危险词就不要运行这个脚本，只处理它的 `S*` 软链。没有危险词才执行：

```text
[ -f /etc/init.d/<名> ] && { /etc/init.d/<名> stop 2>/dev/null; /etc/init.d/<名> disable 2>/dev/null; }
```

本阶段不 `rm` 文件。

2. rc.local：以刚拉回的快照为底本，在本地按第 4 节三条规则改（安装钩子注释、update_docker 注释、R2 的唯一 `exit 0` 挪到末行）。其他字节不动。b64 → `/etc/rc.local.new` → `sh -n /etc/rc.local.new` → md5 一致 → `mv` → `chmod 755`。读回必须同时满足：
   - `grep -c "^exit 0" /etc/rc.local` 去空格后 = 1，且 `tail -1` = `exit 0`
   - `grep -c "^/usr/sbin/update_docker" /etc/rc.local` = 0
   - `grep -E "^[^#]*install_(mbox|pdnterminal)" /etc/rc.local` 无输出
3. crontab：动手前再读一次 `crontab -l` 和 md5。与 Phase 0 的 md5 不同，就再读一次当新底本，只允许这一次重读。新内容 = 底本删掉含 `factory checkMem` 的行，其他行一行不删。R2 若缺则追加，且仅追加：
   - `0 0 * * * /sbin/reboot #routermgmt-reboot`（已按用户授权。副作用是次日午夜约 1 分钟中断）
   - 仅当 `test -x /etc/routermgmt/connlog.sh` 成功时，再追加 `*/5 * * * * /etc/routermgmt/connlog.sh #routermgmt-connlog`。脚本不在就只加重启行并登记。
   R1/R3/R4 不加新行。b64 → `/etc/crontabs/root.new` → md5 → `mv` → `chmod 600` → `/etc/init.d/cron restart` → `crontab -l` 与预期逐行一致。管理行里原有的 netprobe、discovery、connlog、reboot 标记都还在。读回不一致：用快照里的 crontab 按同样方式推回，再 restart，停该台。

**Phase 2 进程**

1. `ps w | grep install_` 只用来找候选 PID。每个 PID 用 `/proc/<pid>/cmdline` 核对。只有路径含 `/usr/bin/install_pdnterminal.sh` 或 `/usr/bin/install_mbox.sh` 的才 `kill <pid>`。
2. 再查 `ps w | grep "[i]nstall_"`。仍有安装器就回到 Phase 1 补软链删除后再杀一次。还在就停该台，不要 killall。

**Phase 3 文件**

只删除 Phase 0 清点里存在的路径，逐个绝对路径 `rm -f`：

- 六个安装器路径（两个花括号名加双引号）
- `/usr/bin/rathole`、`/usr/bin/zcon-ng`、`/usr/bin/zcon-edge-arm64`（清点到才删）
- 清点到的九件套 `/etc/init.d/<名>`
- 仍存在且 readlink 指向这九个名字的 `/etc/rc.d/S*` 软链

不删 `/usr/sbin/update_docker.sh`。不删 `K*` 软链。

**Phase 4 云端点**

四个都写绝对路径：

```text
rm -f /www/cgi-bin/cgi-exec /www/cgi-bin/cgi-upload /www/cgi-bin/cgi-download /www/cgi-bin/cgi-backup
```

保留 `luci`。清点时不存在的，rm 仍然安全。

**Phase 5 数据盘**

- `ps` 能对上 dockerd，或 `mount` 里有 mmcblk0p6 的嵌套挂载：本 Phase 跳过，C6 记未完成，该台不得记全绿。不要 umount。
- 否则只对清点到的路径逐个 `rm -rf`：`/mnt/mmcblk0p6/docker`、`/mnt/mmcblk0p6/by-agent`、`/mnt/mmcblk0p6/by-daemon`、`/mnt/mmcblk0p6/by-watcher`、`/mnt/mmcblk0p6/initmindevice.sh`、`/mnt/mmcblk0p6/data1`。`lost+found` 不动。主分区保持挂载。

**Phase 6 终验（14 项。有未知或失败就不得进下一台之前先把该台隔离）**

残留面：

- C1：`ps w | grep -E "[i]nstall_|by_agen[t]|netbox_daemo[n]|zco[n]|rathol[e]|watche[r]" | grep -v grep | wc -l` 去空格 = 0。非 0 只把 PID 和 cmdline 记入遗留，不要再杀名单外进程。
- C2：Phase 0 的 `/usr/bin` 清点项全部不存在，含两个花括号文件。
- C3：九件套 init.d 都不存在，且 `ls /etc/rc.d/S* | grep -cE "netbo[x]|zco[n]|client_manag[e]|versionInf[o]|timeRestar[t]|mbo[x]|hol[e]|jcgqo[s]|autoupdat[e]"` 去空格 = 0。
- C4：`crontab -l` 无 `factory checkMem`；该台原有管理行都在；R2 有重启行；connlog 行仅在脚本存在时必须有。
- C5：`grep -E "^[^#]*install_(mbox|pdnterminal)" /etc/rc.local` 无输出，且 `grep -c "^/usr/sbin/update_docker" /etc/rc.local` = 0，且 `exit 0` 唯一并在最后一行。
- C6：没有跳过 Phase 5 时，`find /mnt/mmcblk0p6 -type f -perm -u+x | wc -l` 去空格 = 0。find 本身失败记未知。跳过 Phase 5 的记未完成。
- C7：`ls /www/cgi-bin/` 只有 luci。
- C8：`netstat -ltn | grep -cE "5100[2]|982[1]|980[0]|6002[2]"` 去空格 = 0。没有 netstat 就记未知，不要改用别的命令假装通过。另做一条只留档、不计失败的扫描：`grep -R -l -E "pdnterminal|install_mbox|zcon-ng|rathole" /etc/rc.local /etc/crontabs/root /etc/init.d /www/cgi-bin`。命中只进遗留清单，不扩大删除。

不影响面：

- R1：health 仍是 200。
- R2：从现在起等到出现一条 `logread | grep heartbeat` 新记录，时间晚于本台操作开始时间，且与上一条间隔不超过 130 秒。最多等 130 秒。没等到记失败。不要用 30 秒口径。
- R3：隧道实例数等于本台 Phase 0 基线。
- R4：再读 `iptables -L FORWARD -v -n | head -3`。计数器比基线小 = 失败，立刻进入 Phase 7。变大 = 通过。相等就再等 90 秒。仍相等记 PASS-IDLE（这段时间没有新转发），不算失败。禁止为了让计数器上涨去打流量或改规则。
- R5：`iptables -S FORWARD | grep 443 | head -1` 仍以 REJECT 开头。不是就登记遗留，不改规则，该台不记全绿。
- R6：`/etc/routermgmt` 下 netprobe 日志的 mtime 比操作开始时间新，或文件尺寸增加。两条都不成立记失败。

**Phase 7 回退**

心跳断、health 不是 200、或排障口失联：立刻停该台。用快照 tar 里的对应文件按 b64 + md5 + mv 推回。crontab 推回后 `/etc/init.d/cron restart` 并读回。已经删掉的数据盘载荷不回退。
