## 4. 独享、固定、纯净分别怎么落地

1. **独享**：只让雅典娜的指定代理业务使用该最终IP；撤其它设备当前/离线/历史配置和认证的使用资格。只换端口、UUID、域名或节点名，不会凭空变出独立公网IP。
2. **固定**：专用流量只允许落到同一个最终出口。入口坏了可以换另一条通向同一美国落地的中继；美国落地坏了则提示故障，不静默切到BWG/GIA/机场/DIRECT让敏感账号换IP。
3. **纯净**：可控制今后不与其它路由器混用，但不能清空这个IP的历史、保证其是住宅网络，或保证所有网站给出低风险评分。具体服务的可用性/地区/风控要实际测试。
4. **范围**：暂按雅典娜国外代理流量分析；用户主要服务尚待补充。若只固定AI/账号业务，可建专用分流，其他业务保持既有路径；若固定全部国外流量，须覆盖浏览器、应用自带代理、UDP/IPv6等路径。

本机发现多个IPv6地址，当前读取未见IPv6默认路由；雅典娜配置ipv6=false也不能单独证明所有客户端永不旁路。实施时需按实际IPv6作用域/路由验证固定业务，不全局盲禁医院网络。
