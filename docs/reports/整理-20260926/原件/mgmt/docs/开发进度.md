## 已知技术债 / 决策记录

- `jsonfilter`：真机用 opkg 版；测试容器用 Go 编译的同语义工具（`cmd/jsonfilter`，支持 -s 与 stdin）。两者向量已对齐，但表达式集只覆盖 `$.a.b[0].c`/`[*]` 子集——Agent 使用的全部表达式均在子集内。
- 签名原文 hex→二进制在 busybox 用 awk 查表（busybox sed 替换丢反斜杠、printf %x 转义跨版本不稳）；OpenWrt 真机 openssl 若验证不过，install-agent.sh 的自测向量会明确阻止安装。
- 场景 C（崩溃恢复）本地 kill -9 窗口太短（事务 <1s 完成），e2e 采用构造未提交事务验证 `txn_recover_all`；真机网络慢时可自然命中真实窗口。
- `ops` 创建 reboot 任务 deadline 600s；speedtest Session 2 需独立预算。
- metrics 保留 90 天（每小时 DELETE）；月聚合不清理（≥12 个月自然满足）。
- 生产 override 的 TLS 证书生成命令在 compose 文件头注释；自签仅限 WG 内网管理面。
