## 五、今日事故复盘（R2 失联 40 分钟）

**事故链**：v3 部署脚本组装时 python 路径错误导致占位符未替换 → 写入 R2 init（此时 procd 未重启所以未立即暴露）→ **修复后二次执行又复用了同一个坏脚本**（覆盖了第一次的修复）→ 重启后 init 是废文件，隧道全灭 → reboot 后设备无 shell 通道 → 现场处置。
**根因（三层）**：①python 与 Git Bash 的 /tmp 路径不互通（写入静默失败）；②脚本组装后未做内容校验就执行；③执行前未与源 md5 比对。
**修复（已固化）**：组装纯 bash 化；**md5 闸门**（远端写入后必须与源比对）；>8KB 分段传输+逐段校验；DMIT 中转+dbclient exec 流式拉取（绕开 ash 对大单行 echo 吞字符）。
**附带发现**：DMIT ufw 当时未放 28722（切换流量被静默丢弃）——已修并写入 S0 检查单。
