## 一、演进全景（四阶段需求驱动史）

### 阶段 1：立项、分流铁律与硬件定型（2026-09-06 ~ 09-21）

- **核心需求**：
  1. 分布在各地的 20–30 台 OpenWrt 路由器需要集中后台管理系统（远程控制、重启、在线监控、改配置、多 VPS 节点切换）；
  2. **管理通道与代理通道必须物理分离**，保证出口全挂时仍可远程维护；
  3. **国内直连省流量铁律**：国内上网、视频、短视频、直播必须走运营商直连，仅访问境外站点走付费 VPS（曾实测抓到搜狗拼音误走新加坡节点）。
- **关键取舍**：
  - 放弃竞斗云 R619AC（硬件与固件停项，保留交接说明）；
  - 放弃京东云亚瑟 AX1800-Pro（早期 iStoreOS 刷机卡 u-boot）；
  - 确立 **京东云雅典娜 AX6600**（LibWrt + nftables，由 OpenClash 演进为 `mihomo` 直跑）作为本机/医院网关；
  - 确立自研轻量管理台 `mgmt/`（Go + PostgreSQL + Vue + busybox ash Agent），不重复造代理协议轮子。
- **核心见证文档**：
  - [路由器管理系统-开发执行计划.md](路由器管理系统-开发执行计划.md)（v1.2 原始开发任务书）
  - [VPS与路由器系统检查及完善执行计划-20260924.md](VPS与路由器系统检查及完善执行计划-20260924.md)
  - `docs/archive/20260906/`、`docs/archive/20260913/`、`docs/archive/20260914/`、`docs/archive/r619ac/竞斗云刷机交接-20260921.md`

### 阶段 2：SN-R 舰队批量入网与 DMIT 主台时代（2026-09-22 ~ 10-14）

- **核心需求**：
  1. 选定低成本主力机型 **SN-R AX3000（MT7981 / iptables）**，完成 R1–R11 批量自动化刷机与标准配置固化；
  2. 从早期 DO 单台 + WireGuard 升级为 **DMIT 美西管理主台 + 多端点反向 SSH 排灾口（13222–13234）**，打通温备切换与备份链；
  3. 清除设备内置厂商 PCDN 残留与复活钩子，修复 QUIC 竞态、有线 MAC 随机化、WiFi 远程控制与医院/公司网直连兼容；
  4. 引入多出口分流（BWG 东京、DMIT 美西、腾讯新加坡、DO 留退期）。
- **核心成果**：
  - 自动化刷机工具链 `scripts/flash-snr.py` / `flash-batch.py` + 15 关验收体系；
  - 雅典娜管理面迁入平台；完成 `verify/round-1`、`round-2` 四方 AI 核查及 2026-10-01 / 10-12 两次仓库归档整理。

### 阶段 3：抗封锁架构重构——广州国内闭环 + 四层出口防线（2026-10-29 ~ 11-12）

- **核心需求（痛点爆发）**：
  1. 10-29 DMIT/BWG 遇封锁且山东联通国际劣化，导致“管理隧道走国际线，一断全失联”；
  2. 10-30 探索低成本抗封锁线路（Hysteria2 UDP + Cloudflare WS+TLS 2053 + 机场订阅）；
  3. 11-05~11-12 应对 DO 彻底死亡、昌乐 R5 重启竞态透明代理丢链（“微信能开网页全挂”）、雅典娜管理面与出口升级，以及接入新机型 **GL.iNet GL-MT3600BE**。
- **核心成果**：
  - **管理主台迁至腾讯云广州**（纯国内闭环，nginx:8443 → gz-api → 本地 PG；DMIT 退居分叉温备）；
  - **出口建成四层防线**（GIA → BWG-HY2 → CF×2 → 机场订阅，每层均经过封锁演练实证）；
  - 定版 `self-heal v3.1`（排坑 v4 `pidof` 误判）、`mihomo-guard` 双链 `$` 锚点修复、PCDN 八项全清零、升级 SOP v2.0 与 GL.iNet 通用接入 SOP。

### 阶段 4：站点反馈精细治理、防超量限速与多 AI 规范化（2026-11-16 ~ 至今）

- **核心需求（真实用户反馈驱动）**：
  1. **游戏直连修复**：东营 R9 玩 LOL 出现 fake-ip UDP 黑洞无法进对局 → 全舰队补齐 5 个游戏域名的国内真实 DNS 分流；
  2. **国内优先兜底反转**：昌乐 R5 多个国内政务/业务站（`antdu.net`、`xxcg.com`、`hlquant.com`、`bboluo.com` 等）被 `MATCH,PROXY` 误送海外超时 → 全舰队反转兜底为 **`MATCH,DIRECT`** + Loyalsoldier GeoSite 升级；
  3. **防超量分级限速**：66 云 GIA 828GB 套餐实测冲高至 ~95% 被限速（详见 Excel 流量统计表）→ 提出**单台日额 3 GiB，超额仅对海外视频/海外大下载限速 60 kbit/s（雅典娜 100 kbit/s），普通网页/国内/游戏零误伤，支持在线调参、3 秒一键临时解封与永久豁免**；
  4. **多域名抗封与香港新源站**：新购 DMIT HKG（兼迁医院跳板）、上线第 2 CF 域 `6849271.xyz`（HK/BWG 双源站）、雪藏 7 位冷备域 `8364927.xyz`；确立后续“普通 SN 香港主用 + 66云/BWG 后备，雅典娜独立默认”方向；
  5. **多 AI 协作防冲突与仓库治理**：多会话（GLM / Codex / Claude / Gemini 等）并行开发产生脏树与规则漂移 → 落地 `session_guard.py` 协作锁、`build_gz_api.py` 门禁、`governance-20261119/` 五批串行路线，以及 2026-11-21 仓库深度瘦身与唯一真源 `AGENTS.md` 重构。
