## 验证

- **源站功能（决定性）**：GZ 境外视角 raw-socket TLS+WS 升级握手 → `HTTP/1.1 101 Switching Protocols` + 正确 `Sec-WebSocket-Accept`（**WS-101-OK**）。此前 curl 系测试超时为其自身对裸升级握手的行为怪癖（sing-box 日志显示连接到达并被正确处理）。
- **限源**：GZ（非 CF 来源）→ 2053 被拒 = 设计预期；CF 边缘与回环放行。
- **回程路径备注**：R2 家宽→HK TCP:22/2053 被掐（CN→HK 家宽 TCP 干扰）；**不影响源站角色**（设备→CF 边缘→HK 源，永不直连）；GZ→HK 全通（147ms）。

## 过程坑（如实）

1. 部署长脚本经 SSH stdin 超 300s 超时中断 → 分阶段幂等续跑。
2. Ubuntu 26.04 无预装 nftables/iptables → apt 装齐。
3. 嵌套 heredoc 被 `sh -s` 吞掉导致 guard 脚本残缺（`nft -f` 空参）→ 改为 SFTP 上传独立 .nft 规则文件 + 一行 shell 脚本，彻底消除嵌套。
4. nft comment 需双引号（单引号=语法错）→ SFTP 读改写修正。
5. R2 侧一次性 mihomo 验收因 R2→HK TCP 被掐不可行（502/000），改用 GZ raw-socket 验收；R2 测试残留（测试实例+配置）已清理。
