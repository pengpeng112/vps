## 2. 根因定案："google/youtube 全挂" = 测试方法假象

证据链：
1. 节点级测试三节点全通：BWG→google 101ms、CF2→google 317ms、CF2→youtube 326ms。
2. 显式代理（按域名出站）`curl -x :7890` 全通：google 204、youtube 204、wikipedia 200、x.com 200。
3. **LAN 真实用户活跃连接实证**：192.168.132.245 正在经 BWG 访问 voachinese.com / bloomberg（connections API 实抓）。
4. 运营商 DNS 污染实锤：www.google.com 经 219.146.1.66 → 185.45.5.35（假 IP）；经 dnsmasq(192.168.132.1) → 198.18.0.33（mihomo fake-ip）。

机制：设备本机 curl 用 /etc/resolv.conf（运营商 DNS）→ 拿污染 IP → mihomo OUTPUT 透明接管后 `override-destination: false` 按原目的 IP（污染 IP）经节点转发 → 连假 IP 超时。**真实 LAN 用户走 dnsmasq→mihomo DNS→fake-ip→按域名匹配→节点远端解析，完全不受污染影响**。今后设备侧外网测试一律用 `curl -x :7890`（域名出站）或节点 delay 测试，禁止用本机直连 curl 判定"外网不通"。
