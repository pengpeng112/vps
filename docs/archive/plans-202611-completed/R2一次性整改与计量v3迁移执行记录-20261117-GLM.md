## 2. 计量 v3（B01/B02/B03/B10/B11 对策）

- **单一原子权威状态**（schema3，含上一采样计数器＋当日账），tmp+mv 一次提交；日账视图文件为派生物，可重建（G03-6 实证：删视图后重算不重不漏）。
- 上一状态与当前采样为**两个独立文件参数**喂同一 awk（FILENAME 区分），定点键提取；v2 的"PREV 路径当内容用/两样本拼单行喂 NR 分支 awk"两类根因物理上不再可能。
- **读失败≠0**：链级读失败端点保留上一好值、贡献 0、health=degraded、rc=3；恢复后差额一次入账（G02：100→恢复 130 计 30，不丢不重）。全失败/不可写 rc=1 且原状态不被破坏。
- **boot_id 全量＋规则代次**：重启全体重定基线（日账保留）；同 boot 计数下降＝链重建逐端点重定基线（不为负、不伪补）；新端点首见基线（不把规则晚插的历史累计灌进当天）；端点消失 drop_ep 降级＋日账 partial 标记。
- **跨午夜**：整段增量记入新一天＋partial=true（不伪分摊）；时钟回拨记 time_skew。日键固定 Asia/Shanghai 用 POSIX `TZ=CST-8`（Olson 名在 busybox/MSYS 会静默回退 UTC——真机与本地双重实证）。
- **端点注册真实化**（B11）：rules-v3.conf 由生成器从 `/etc/mihomo/config.yaml`＋机场缓存（块式/流式 YAML 双兼容）生成真实 IPv4/协议/端口元组；域名型节点进 coverage.json 未解析名单；计量每轮检查激活组（NODE-PICK/US-MEDIA/AUTO 链式解析到具体节点）未注册即 health=degraded（"没有覆盖的路径不能报可信总账"）。机场节点名含 emoji/中文：tag 清洗折叠＋同名自动加序号。
- **规则幂等**：只按 comment 标签判在、自链内补缺（无 target 纯计数规则，与现网 v1 安装的同款；绝不带 RETURN 截断他人计数）；jump 缺失只降级不插；不动 built-in/不 DROP/不改路由。
- busybox 兼容实证：无用户自定义函数；`val (expr)` 会被 busybox awk 误判函数调用（已改中间变量）；设备 /tmp 干跑通过后才进 Phase B。
