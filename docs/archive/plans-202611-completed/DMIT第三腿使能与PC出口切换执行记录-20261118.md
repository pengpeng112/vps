## 2. 试点结论：DMIT 线路层暂不可用（如实）

双向抓包对拍定论：
- R2→DMIT 方向 **通**：QUIC Initial（UDP 1280B）到达 DMIT 网卡（DMIT tcpdump 实证 5/5＋握手重试包）。
- DMIT→R2 方向 **断**：服务器响应包已从 DMIT eth0 发出（37B/1279/1280B tcpdump 实证），但 **R2 侧抓包 20/20 全为发出包、零回包**——回程 UDP 在中途被丢弃。
- 与 TCP 全端口被断同属本次封锁行为；ping(ICMP) 通、出向 UDP 通、回向 UDP 断。
- mihomo 侧表现：节点 alive=false，delay 测试 "An error occurred"（QUIC 握手无响应）。

**处置**：节点保留在 NODE-PICK 兜底位（alive=false 不影响 BWG-HY2 主路径；fallback 顺序 BWG→DMIT→BWG-VLESS）。线路恢复（回程 UDP 或 TCP 任一解除）后无需再改配置，节点自动可用；届时 delay 测试即通过。UFW 放行保留（服务正常，不撤）。
