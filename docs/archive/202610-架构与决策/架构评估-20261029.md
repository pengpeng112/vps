### 根因分析
1. **单点依赖**：全部管理通道（SSH 隧道）和大部分出口流量都依赖 DMIT 或 BWG 的国际线路
2. **被墙风险**：普通线路 IP（DMIT/BWG）随时可能被 GFW 封锁（本次实证）
3. **家宽国际路由脆弱**：山东联通到美西/东京的路由，高峰或敏感期大面积劣化
4. **无国内中继**：设备管理必须出海，家宽国际断了就彻底失联

## 二、当前架构（今天的现状）

### 管理通道（远程控制路由器）
```
路由器 ──SSH隧道──→ DMIT(28722) ←── 我/平台
路由器 ──SSH隧道──→ 66云GIA(28722) ←── DMIT ←── 我（第五端点，应急用）
路由器 ──SSH隧道──→ BWG/DO/TX（备用腿，无后端）
```
**问题**：全部需要国际线路。家宽国际断 = 管理断。

### 出国流量（站点上网）
```
路由器 LAN 客户端 ──mihomo──→ 出口节点（66云/BWG/DMIT）──→ 国外网站
```
当前 7台中 6台已在 66 云 GIA（精品线路，稳定），R4 还在 DMIT（待切）。

## 三、改进方案：管理与出国分两条线路

### 核心思路
```
管理通道（远程控制）──走国内路由── 广州服务器 ──云出口──→ DMIT 后端
出国流量（站点上网）──走国际路由──→ 66云 GIA / BWG / DMIT
```

**管理通道**永远走国内路由（不受国际断影响）；
**出国流量**走国际路由（但多节点互备+自动切换）。

### 具体架构
```
┌─────────────┐     国内路由(10ms)     ┌─────────────┐    云出口(150ms)    ┌─────────┐
│   路由器     │ ──────────────────→ │ 广州服务器    │ ────────────────→ │ DMIT    │
│  (各站点)    │   SSH 隧道:28722      │ 134.175...  │   SSH 接力:8443     │ 后端    │
└─────────────┘                      └─────────────┘                     └─────────┘
      │                                                                     ↑
      │  国际路由（出国流量）                                                  │
      ├──────────→ 66云 GIA (154.36.137.54:443)  ← 主用（精品）              │
      ├──────────→ BWG 东京 (74.82.193.113:443)  ← 备用                     │
      └──────────→ DMIT LAX (179.255.137.64:443) ← 备用                     │
```

### 两条线路完全独立
| 线路 | 走哪 | 用途 | 故障影响 |
|---|---|---|---|
| **国内线** | 设备→广州→DMIT | 远程控制/心跳/配置下发 | 仅当国内路由故障才断（概率极低） |
| **国际线** | 设备→66云/BWG/DMIT | 站点上网（代理） | 互为备份+自动切换 |

## 四、安全评估（不影响现有使用和远程）

### 不影响的使用
1. **站点上网**：代理流量走 mihomo 出口，与 SSH 管理隧道完全独立
2. **现有管理通道**：DMIT 主端点不动，新增第六端点（广州）只是多一条路
3. **现有排障口**：DMIT 132xx 不动，新增广州侧的对应端口

### 改动清单（只增不改）
| 操作 | 影响 |
|---|---|
| 广州服务器装 sshd 双端口(22+28722) | ✅ 无影响（已装好） |
| 广州服务器部署到 DMIT 的 SSH 接力 | ✅ 只加 systemd 服务 |
| 设备 authorized_keys 加广州条目 | ✅ 追加，不改已有 |
| 设备 tunnel.conf 加 VPS6_HOST | ✅ 追加，不影响现有五端点 |
| v3 init 加第六端点支持 | ✅ 向后兼容，无 VPS6 就不启动 |
| 出口节点切换 | ✅ mihomo 配置级，秒级生效/回退 |

### 风险点及对策
| 风险 | 概率 | 对策 |
|---|---|---|
| 广州服务器本身故障 | 低 | 设备有 DMIT/66云/BWG/DO 五个备端点 |
| 广州→DMIT 路由断 | 低 | 走 GIA 中继（或直接 SSH 到 DMIT:28722） |
| 新配置部署时隧道断 | 低 | 分批推送+每台验证心跳再下一台 |
| 66云被封 | 中 | BWG/DMIT 互备+lazy:false 自动切换 |
