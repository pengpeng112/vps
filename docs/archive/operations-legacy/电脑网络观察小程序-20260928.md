# 电脑网络观察小程序

建立于2026-09-28，适用当前PC单接雅典娜拓扑。程序：[network_watch.py](../../scripts/network_watch.py)；定时注册：[register_network_watch.ps1](../../scripts/register_network_watch.ps1)。观察数据位于`F:\vps\webprobe\network_watch\observations-YYYYMM.jsonl`，按月追加，不覆盖旧`webprobe.csv`。

程序每15分钟检查一次电脑默认网关及3次网关ping；并行请求Google 204、gstatic 204、Google Mail首跳301、百度默认解析和两条固定IP对照。固定坏地址`110.242.70.57`是诊断对照，预期可能超时，报告单列，不算常规网站故障；正常对照为`110.242.69.21`。固定IP请求保留百度域名和TLS校验。每项只发起一次HTTP请求；不读业务网页正文、不登入服务器、不改代理或路由器配置。

记录每次curl退出码、HTTP状态、解析/TCP/TLS/首字节/总耗时和目标IP。仅预期HTTP状态且curl退出码0算成功；28=超时、6=DNS失败、403等为HTTP状态异常。对照地址长期可能变化，若CDN调整，应标记对照失效并重新核验，不自动改系统hosts。

操作：

```powershell
python F:\vps\scripts\network_watch.py --report --hours 24
python F:\vps\scripts\network_watch.py --report --hours 48
Get-ScheduledTask -TaskName VPS-NetworkWatch
Get-ScheduledTaskInfo -TaskName VPS-NetworkWatch
```

临时暂停/恢复：`Disable-ScheduledTask -TaskName VPS-NetworkWatch` / `Enable-ScheduledTask -TaskName VPS-NetworkWatch`。移除任务：`Unregister-ScheduledTask -TaskName VPS-NetworkWatch -Confirm:$false`。这些操作不删除采样文件。

观察报告是PC侧公开目标样本，不能代替真实网页加载、视频播放、路由器netprobe的两条VPS线路丢包率或医院链路验收。每轮记录当前默认网关，网关漂移须单独核查；两台VPS出口质量沿用雅典娜现有netprobe。报告只读本地JSONL，不触发网络请求。
