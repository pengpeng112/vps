# 新 SN-R1-AX3000 刷机+录入 SOP（2026-09-28 首台 rtr-a9bcba 实测全流程）

> 适用：同款 JCG 出厂固件（OpenWrt 21.02-SNAPSHOT, aarch64, MT7981）的新 AX3000。
> 单台耗时约 30-40 分钟。先读《SN-R1-AX3000-记录与刷机准备-20260923.md》§4/§8。
> 首台凭证：`F:\vps\backups\.new-snr-pw`；总表 §3c。

## 前置物理条件
- 新路由 WAN ← 雅典娜任意 LAN 口（确认该口在 br-lan 桥内！竞斗云隔离口教训）
- PC 网线 ← 新路由 LAN 口；PC 无线接外网保底（刷机期间管理通道不断）
- PC 给以太网配静态 192.168.132.50/24（**无网关 + 接口跃点 9999**，防止抢占无线上网——09-28 踩过）；再加明细路由去雅典娜：`route add 192.168.2.0 mask 255.255.255.0 192.168.132.1`

## 流程（每台）
1. **登录**：telnet 192.168.132.1 → root / abc@1234（如拒：查机身标签或试 12345678）
2. **换 root 密码**（PC 生成 `openssl passwd -1`，telnet 写 /etc/shadow），随后 SSH 可用即弃用 telnet
3. **§4 预装清理**：`/etc/init.d/{dockerd,telnetd,ksmbd,miniupnpd,start_autoupdate,mtk_dut,wsdd2}` stop+disable；杀残留进程；`/etc/init.d/done` 里 telnet 行注释；`rm -rf /etc/m-box`；crontab 只留 factory checkMem
4. **NTP 裸 IP**（必须，否则时钟停在出厂时间→心跳 HMAC 全拒）：`uci add_list system.ntp.server='192.168.2.1'`（+120.25.115.20/203.107.6.112），`/etc/init.d/sysntpd restart`，`date` 核对
5. **openssl3 全局替换**（仓库 firmware/snr1-openssl3/usr/）：usr/bin/openssl → /usr/bin/openssl；libcrypto.so.3、libssl.so.3 → /usr/lib/；`openssl version` 应为 3.0.16
6. **管理台录入**：
   - PC 调 mgmt API：`POST /api/v1/devices`（带名字）拿一次性 enroll_code → `POST /api/v1/devices/enroll` 得引导包（存 backups/pkg-snrX.json，600）
   - 引导包注入 `"mgmt_url": "https://127.0.0.1:18443"` 后传路由器 /tmp/stage/pkg.json
7. **装 agent**（仓库 mgmt/agent/ 13 个文件 → /tmp/stage，跑 install-agent.sh）
   - **本固件无 `install` 命令**：脚本里所有 install 行会失败，须按脚本清单手工 cp+chmod 补齐（agent/handlers/access-fw/netprobe/init×3/wan-watch 三件/tunnel.conf.example/setup-mgmt-tunnel/mihomo-ipt）
   - `uci -q delete network.wg0`（无 wg 二进制，防止污染 network 配置；wg0.conf 文件保留）
8. **隧道**：`sh /usr/sbin/setup-mgmt-tunnel.sh`（生成 RSA key + tunnel.conf）；tunnel.conf 追加：
   `RSSH_REMOTE_PORT=1322X`（每台一个新端口：13223 已用，后续 13224/13225…）`RSSH_TARGET=192.168.132.1:22`
   - VPS /root/.ssh/authorized_keys 追加（注意换端口与注释）：
     `no-agent-forwarding,no-X11-forwarding,no-pty,permitopen="10.10.0.1:8443",permitlisten="127.0.0.1:1322X" <pubkey> rtr-mgmt-tunnel-snR(X)`
   - pin-hostkey（指纹从 PC `ssh-keyscan` 取 ed25519 行）：`sh /usr/sbin/setup-mgmt-tunnel.sh pin-hostkey SHA256:xzLDDn+qC+CokaAi76Q/kXecto/nwM+sN+l7KC5mIIM`；若本机 dbclient 协商 RSA 导致 pin 失败→留空走 -y 兜底（已接受）
   - `/etc/init.d/mgmt-tunnel enable && restart`；路由器 `curl -sk https://127.0.0.1:18443/api/v1/health` =200
9. **mihomo**：从雅典娜拉（雅典娜 busybox 无 httpd → 用 /www + uhttpd：`mkdir /www/.mgmt-tmp; cp /etc/openclash/core/clash_meta →mihomo; GeoSite.dat; Country.mmdb; /etc/mihomo/run.yaml →config.yaml`，路由器 wget http://192.168.2.1/.mgmt-tmp/…，完删 /www/.mgmt-tmp）
   - init.d/mihomo 模板见首台 /etc/init.d/mihomo（procd + 等 9090 后跑 /etc/mihomo-ipt.sh）
   - mihomo-ipt.sh 仓库版已含 TX 43.134.46.44 RETURN；启动后验证 `iptables -t nat -S PREROUTING | grep -c MIHOMO` =2、QUIC drop=1、`curl -x http://127.0.0.1:7890` 出口=节点 IP
10. **发布配置**：assignments/batch 绑 TX(secondary,apply=false) → 绑 DO(primary,apply=true) → 等 switch_node ok → `set_proxy_state enabled=true` 回 AUTO
11. **Wi-Fi**：本固件预置 12 个 iface（mesh/guest/ssid3-8）——删到只剩 ra0/rax0，各设 SSID+psk2 强口令，RADIO2G/RADIO5G disabled=0
   - **⚠️ MTK 私有 WiFi 栈（09-28 首台实锤）**：uci wireless 只是镜像、改了不生效！真实配置在 `/etc/wireless/mediatek/mt7981.dbdc.b0.dat(2.4G)/b1.dat(5G)/DBDC_card0.dat`——sed 改 `SSID1=` 与全部 `WPAPSK*=槽位` 后 `wifi down && wifi up`，用 `iwconfig ra0` 验证实际广播 SSID。uci 里同时改一遍保持镜像一致。
12. **验证闭环**：管理台设备 online；netprobe.log 有 cn/vps/tx 三行；PC 有线（静态 132.50 或 DHCP）经它上网（nslookup→fake-ip、ping 8.8.8.8 走转发）；`ls /etc/rc.d/` 见 S99mihomo/S99routermgmt/S98mgmt-tunnel

## 已知坑（首台实测）
- busybox 精简：无 install/base64/timeout/httpd；openssl 1.1.1（已全局换 3）
- telnet 登录口令与 SSH 不同源时以 telnet 实测为准；换密后 telnet/SSH 同时生效
- 心跳 401 排查顺序：时钟（date）→ 隧道 health → agent.conf 字段
- 首台凭证位置：F:\vps\backups\.new-snr-pw；总表 §3c
