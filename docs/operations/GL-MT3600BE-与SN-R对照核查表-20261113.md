## USB 5G/LTE modem 正式方案（VPS 访问可行性）

### 硬件确认（已查证）
- Beryl 7（GL-MT3600BE）**无 SIM 卡槽**
- GL 固件已预装 modem 驱动：`qmi_wwan` / `cdc_ether` / `cdc_ncm` / `option`（GSM）
- GL 固件已预装 modem 服务：`modem` / `modem-init` / `modem_auto` / `modem_signal` / `gl_tethering`

### 方案 B 实施步骤（正式）

**① 采购 USB 5G/LTE modem**（以下型号经 GL.iNet 官方兼容验证）：
- 华为 E3372h-320（4G，便宜稳定）
- 中兴 MF833U1（4G）
- 移远 EG25-G（4G 模块，需 USB 转接板）
- 广和通 FG150（5G 模块，需 USB 转接板）

**② 插卡接线**：
- SIM 卡插入 USB modem
- USB modem 插 GL 的 USB 口（Beryl 7 的 USB-C 供电口旁的 USB-A 口）
- GL 面板 → Internet → Cellular → 自动识别 → APN 按运营商填（移动=cmnet/联通=3gnet/电信=ctnet）

**③ VPS 访问验证（关键）**：
| 检查 | 标准 |
|---|---|
| GL 获得 cellular WAN 地址 | `ip addr show wwan0` 或 `usb0` 有 IP |
| GL→广州 28722 经蜂窝 WAN 连通 | `ssh -p 28722 root@134.175.151.213` 从 GL 经蜂窝 WAN 出得去 |
| GL→GIA 443 经蜂窝 WAN 连通 | mihomo 节点连通测试 |
| 隧道自动跟切 | 拔以太网 WAN 后，GL 隧道经蜂窝 WAN 重连广州（respawn 无限重试） |
| 反向口恢复 | 广州 13234 在蜂窝 WAN 下重新 LISTEN |

**④ 流量路径**：
```
GL WiFi 客户端 → GL mihomo → VLESS 443 → GIA（经蜂窝 WAN 出海）
GL 管理隧道 → 广州 28722（经蜂窝 WAN 直连，国内方向）
```

**⑤ 双 WAN failover**：
GL 面板 → Internet → Multi-WAN → 设"以太网优先、蜂窝备份"（GL 固件内置 failover，自动切换）

### 结论
**方案 B 完全可行**：USB modem 插卡后 GL 获得蜂窝 WAN，VPS（GIA）经 VLESS/TCP 443 连通，管理隧道经蜂窝 WAN 直连广州，与 SN-R 标准一致。蜂窝下 HY2(UDP 34568) 可能被运营商 QoS，但 NODE-PICK 首选 GIA-VLESS(TCP 443) 已是正确顺序，无需改配置。
