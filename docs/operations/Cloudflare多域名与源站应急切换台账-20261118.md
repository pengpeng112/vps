## 4. 故障A：切某一子域源站

前提：域名/边缘正常，证据指向源站故障或预算不足；替代源站有容量、同凭据/路径、CF限源保护且受控验证通过。

1. 取得相应维护锁，读取record ID、旧A/proxied/TTL、Origin Rule/LB覆盖，受控保存快照；只改目标一条，不动NS/不关橙云。
2. A改为已验替代源站，保持Full/WS；不能看到521就盲切。
3. 两来源观察新连接WS、完整代理与出口转向；记录真实收敛耗时，**不保证1—3分钟全球生效**，旧长连接可能需重连。
4. 5分钟仍未验证新连接，检查账户实际状态/规则后决定回旧A；旧源健康才能回，避免无限抖动。
5. 同域同凭据通常设备无需发布；不承诺连接不断流。回GIA先核对额度。
