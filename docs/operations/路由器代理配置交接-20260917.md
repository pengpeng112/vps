## 5. 本次实战踩出的新坑（按值钱程度排序）

1. **ttyd 登录不需要密码**：该固件 root 密码为空，`root\r` 直接进 shell。之前"SSH root/password 被拒"之谜就此解开（空密码拒绝密码认证）。
2. **ttyd 自动化铁律**：Playwright 的 `press("Enter")` 到不了终端，回车必须嵌在 `type()` 字符串里用 `\r`；终端渲染截图严重滞后/重影，**可靠模式 = 命令输出重定向到 `/tmp/*.txt` → quickfile readfile 读回**。
3. **busybox 没有 `install` 命令**：`install-agent.sh` 第 91-94 行在真机会报 `install: not found`，agent 二进制/handlers/init 需手动 `cp` 补装（已做；给 mgmt 上游提修复建议：改用 `cp`+`chmod`）。
4. **install-agent.sh 的 WG 配置在 netifd 下不完整**：它只写 `/etc/wireguard/wg0.conf`（netifd 根本不读），uci 里缺 `option private_key` 和 `wireguard_wg0` peer 段 → 接口起来了但没有 peer。补法（本次已写入）：uci 设 private_key（从引导包 jsonfilter 取值）、追加 peer 段（public_key=hub 公钥、endpoint、allowed_ips、route_allowed_ips）。
5. **quickfile 实测结论**：`writefile` 可以覆盖已存在文件（createfile 报 already exists 无碍）；**`.crt` 扩展名被过滤**（换 `.pem`）；`readfile` 返回 JSON 信封 `{"content":...,"success":...}`。
6. **Agent→管理台 TLS**：自签证书必须把 fullchain 追加进路由器 `/etc/ssl/certs/ca-certificates.crt`，否则 curl 校验失败（http=000）。
7. **引导包没有 mgmt_url 字段**：真机安装必须 `MGMT_URL_OVERRIDE=https://10.10.0.1:8443`。
8. **fw4 忽略 include 段的 `family`/`reload` 选项**（警告无害，脚本照跑）。
9. **1GB 内存 VPS 构建前端会 OOM**：`frontend/Dockerfile` 已加 `NODE_OPTIONS=--max-old-space-size=2048`（swap 加持）；go 后端构建无碍。
10. **wireguard-tools/kmod 该固件内置**（vsean 源），opkg 直接可用，不用找 kmod。
