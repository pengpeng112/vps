## 二、接入核验清单（逐项打勾才算接入完成）

### §1 身份与端口
- [ ] `grep DEVICE_ID /etc/routermgmt/agent.conf` 验明真身（**"SSH 通"≠在线**，13224/13227 换防后尤其重要）
- [ ] 反向端口全局唯一：R2=13223、**R3=13227**、R4=13224、R5=13225、R6=13226、R7 起=132xx 顺延（flash-snr.py 自动分配）
- [ ] DO 侧 authorized_keys 该设备行 permitlisten=独占端口，**多目标 permitopen 必须重复选项格式**（`"A",permitopen="B"`，逗号列表非法会报废整行）
- [ ] 口令=统一口令；本地档案 `backups/.snrN-pw`（没有就建）

### §2 管理隧道（三路 + 温备）
- [ ] mgmt-tunnel **v2**（多端点并行）：DO 直连(:18443) + TX(:18444) + BWG(:18445)，`deploy-parallel-tunnel.py --num N --with-bwg`
- [ ] **respawn `3600 0 0`**（无限重试；5 次上限会在服务端故障期耗尽后永不自愈）
- [ ] **`-o ExitOnForwardFailure=yes`**（-R 被占时退出重试，防半开永卡）
- [ ] **MGMT_TARGET=127.0.0.1:8443（温备定稿）**；⚠️ 正常态 :18444/:18445=000 是**设计行为**（TX/BWG 待命容器平时停着），只有 :18443 应为 200；DO 整挂演练时才启动待命台接管
- [ ] mgmt-port-discovery.sh 在位（agent 心跳失败自动选路）
- [ ] 验证：心跳 online + discovery 选中 18443 + rssh 反向口在 DO 可达

### §3 代理绑定与验收
- [ ] `point-check.py --num N` 体检（三节点 ICMP/TLS/路由特征/运营商）
- [ ] 按决策表定主用：联通线→BWG 东京主用、腾讯双备；移动/广电→腾讯 HY2 主用（按实测）
- [ ] failover_priority 显式排序（主=0，备按序 1/2）
- [ ] 发布前 preview **六项核对**（匹配完整规则行，含 `,no-resolve` 后缀）：NODE-PICK 顺序/出站字段/掩码/gstatic/**dl.google.com→PROXY**/DO 与节点 IP 直连规则
- [ ] 发布 apply → 任务 ok（exit_ip 双次校验）→ **P5 验收**：出口 IP×2（国外探测点！）、youtube×8、google/gstatic、百度直连、三并发 12s 下载无死流
- [ ] 健康检查失败自动回滚后**不连续重发**，先查 health.log 定位

### §4 WiFi 状态持久化（用户 10-01 定稿要求）
- [ ] **语义：开了不自动关，除非人工关闭；新设备默认关**
- [ ] agent handler md5 ≥ `2c58a38a`（开启建 `wifi.enabled` 标记/关闭删；300s 自动恢复路径也建标记）
- [ ] rc.local **v3 钩子**（三态+重试）：`(sleep 8; _w=up; [ -f wifi.enabled ] || _w=down; 6×5s 重试 ifconfig ra0/rax0)`——MTK 驱动开机初始化要十几秒，固定 sleep 无效；dat 的 RadioOff=1 是默认关的兜底
- [ ] SSID=`SN-R{n}-AX3000(-5G)`、PSK=舰队统一值 `[REDACTED]`（**密码三类统一政策**见 backups/SN-R系列凭证总览.md：root/LuCI=[REDACTED]、WiFi=[REDACTED]，各自全舰队同值）
- [ ] **WiFi 凭据必须核验 dat 层**（`grep WPAPSK1 /etc/wireless/mediatek/mt7981.dbdc.b*.dat`）——R3 教训：早于 dat 写入段刷机的设备广播的是出厂 WIFI-xxx/12345678，uci/网页层一致也是假象；不符则 sed dat 三文件全部 WPAPSK 槽位 + `wifi down/up` + 复读验证
- [ ] 验证=重启后 `ip link show ra0` state **UP**（iwconfig 显示 ESSID ≠ 射频 UP）

### §5 登录页
- [ ] 无默认密码回显（uci `system.@system[0].password` 清空 + 模板与 R3 修复版 md5 对拍 `c98e66b2`）
- [ ] autocomplete 属性在位（浏览器可存密码）
- [ ] HTTP 200 且无 abc@1234（明文/base64 两种形态都查）

### §6 坑前置检查（先于一切配置排查）
- [ ] **闪存损坏三特征**（断电后高发）：配置文件全 0x00 / 二进制段错误（`mihomo -v` rc=139）/ geo 文件 md5 与好机不符 → 从好机三件套逐级 md5 搬运，勿查配置
- [ ] 假在线陷阱：反向口被占时"SSH 通"的是别的设备
- [ ] 测量假阴性：测代理出口用国外探测点（ip.3322.net 走 GEOIP,CN 直连）；busybox date 无 %N 用 curl `%{time_total}`；ps 计数用 `grep "[x]x"`；ops 接口带 Idempotency-Key

### §7 探针
- [ ] `fleet-netprobe-install.py --num N`（幂等；netprobe.sh 含 bwg 目标）
- [ ] cron `*/5` 条目 + **rc.local netprobe-cron-restore 钩子**（厂商开机重写 crontab，条目必丢）
- [ ] 首轮采样可见（log 有 4 行 icmp + 2 行 http_）

### §8 全功能测试清单（交付门）
- [ ] 任务链：ping_test / set_wifi（幂等开）/ reload_proxy / reboot（boot_id_changed=true）
- [ ] **双向 switch_node**：切备用节点验出口实测 → 切回主用（TX-VLESS 回滚属管理面探测抖动时，查 health.log 再决定，不连发）
- [ ] **重启自愈×2**：三路/心跳/mihomo/探针 cron/WiFi 状态/配置版本/登录页全部保持
- [ ] 隧道韧性抽验：rssh 半开后 -K 30 + EOF + 无限重生应在数分钟内自愈

### §9 流程纪律
- [ ] **试点→推广**：新标准先在一台可物理接触的设备调好测全，再批量
- [ ] 文档：接入记录写 `docs/plans/`、当前状态短条目、AGENTS.md 速览同步
