## 5. 修复过程中的关键缺陷（记录）

- Authorization 前缀长度按 13 计算导致全部 HMAC 401（"HMAC-SHA256 " 实为 12 字符）。
- 签名原文末尾误加 LF 导致 ed25519 验签失败（§7.5 要求末尾无 LF）。
- busybox sed 替换串 `\\x` 丢反斜杠、Go 版 jsonfilter 缺 stdin 支持 → agent 验签/取组状态失败；分别改 awk 查表转换、补 stdin。
- 空 IdempotencyKey 以 `''` 入库撞 (device, created_by, key) 部分唯一索引 → 未提供时生成 `auto-` 随机键。
- 先 upsert 新 primary 再降级旧 primary 触发 one_primary 唯一索引 → 调整顺序并加回归测试。
